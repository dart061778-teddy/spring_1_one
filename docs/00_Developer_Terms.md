# 開発用語集 (Developer Terms)

## 1. 基本アーキテクチャおよびパターン用語
- **MVCモデル (Model-View-Controller)**: アプリケーションをデータ処理（Model）、画面表示（View）、制御ロジック（Controller）の3つの役割に分離して設計するアーキテクチャパターン。
- **コントローラー (Controller)**: クライアントからのHTTPリクエストを受け取り、適切なサービスやDAOを呼び出して処理結果をモデルに格納し、ビューに渡す役割を担うコンポーネント。
- **マッパー (Mapper)**: MyBatisにおいて、JavaのインターフェースとXMLに記述されたSQL文を結合し、データアクセスを抽象化するコンポーネント。
- **依存性注入 (Dependency Injection - DI)**: オブジェクト間の依存関係を外部（Spring コンテナなど）から注入し、コードの結合度を下げる設計手法。
- **リポジトリ / DAO (Data Access Object)**: データベースへのアクセスやクエリ実行をカプセル化し、データ永続化処理を担当するレイヤー。
- **DTO (Data Transfer Object)**: レイヤー間（コントローラーとサービス、DB間など）でデータをやり取りするために使用されるデータ保持用のオブジェクト。
- **Java Beans**: 再利用可能なソフトウェアコンポーネントの設計規約であり、引数のないデフォルトコンストラクタを持ち、カプセル化されたフィールドに対するGetter/Setterを備えたJavaクラスの形態。
- **ライフサイクル (Lifecycle)**: オブジェクトの生成、初期化、実行から破棄に至るまでの全体的な生存期間や一連の処理のながれ。
- **アーキテクチャ全体像 (Overall Architecture)**: システム全体の各コンポーネント（コントローラー、DAO、データベースなど）がどのように連携し、データを処理するかを体系化した構造。

## 2. Java および Spring Boot コア用語
- **アノテーション (Annotation)**: クラスやメソッドなどにメタデータを付与し、フレームワーク（Spring など）に特別な動作や設定を指示する機能（例: `@Controller`, `@Autowired`）。
- **コンポーネントスキャン (Component Scan)**: 指定したパッケージ内をスキャンし、アノテーションが付与されたクラスを自動的に Spring Bean として登録する仕組み。
- **インセプション / 自動再起動 (DevTools)**: 開発時にソースコードの変更を検知して自動的にアプリケーションを再起動する機能。
- **自動設定 (Auto-Configuration)**: クラスパス上の依存関係や設定に基づき、Spring Bootが自動的に必要なBeanやインフラストラクチャを構成する仕組み。
- **エントリポイント (Entry Point)**: アプリケーションの実行が開始される起点となるメソッド（`main`メソッドなど）やクラス。
- **リクエストマッピング (Request Mapping)**: 送信されたHTTPリクエストのURLやメソッド（GET/POST）を、特定のJavaメソッドに対応付ける仕組み。
- **データバインディング (Data Binding)**: クライアントから送信されたフォームデータやパラメータを、Javaオブジェクトやメソッドの引数に自動的に結びつけて渡す機能。
- **フォワード / ビュー返却 (View Forwarding)**: 処理結果を保持したまま特定のJSPなどの画面テンプレートに処理を引き渡し、レスポンスとして描画する仕組み。
- **防禦的プログラミング (Defensive Programming)**: 不正な入力値や予期せぬ例外（`try-catch` によるパースエラー処理など）によるシステム異常を事前に防ぐためのコーディング手法。
- **統合テスト (Integration Testing)**: アプリケーションの複数コンポーネントやSpringコンテナ（ApplicationContext）全体を組み合わせて、正常に連携して動作するかを検証するテスト手法。
- **スモークテスト (Smoke Testing)**: アプリケーションが基本的な機能を満たし、起動やコンテキストロードにおいて致命的なエラーが発生しないかを簡易的に確認する初期テスト。

## 3. バージョン管理およびGit用語
- **リポジトリ (Repository)**: ソースコードやファイルの変更履歴を保存・管理する場所。
- **コミット (Commit)**: ファイルの変更履歴をローカルリポジトリに記録する作業。
- **プッシュ (Push)**: ローカルリポジトリの変更履歴をリモートリポジトリ（GitHubなど）に送信してアップロードする作業。
- **プル (Pull)**: リモートリポジトリの最新の変更履歴をローカルリポジトリに取得して統合する作業。

## 4. ビルドおよび依存関係用語 (Build & Dependency Terms)
- **ビルドツール (Build Tool)**: ソースコードをコンパイルし、テストやパッケージングを実行して実行可能なファイルに変換する自動化ツール（例: Gradle）。
- **依存関係 (Dependencies)**: アプリケーションの動作に必要な外部ライブラリやフレームワークのモジュール。
- **プラグイン (Plugin)**: ビルドツールに特定の機能（Spring Boot サポートや Java コンパイル設定など）を追加拡張する仕組み。
- **ツールチェーン (Toolchain)**: 開発において使用されるコンパイラやランタイム（Java バージョンなど）の一連のツール群を管理する仕組み。

## 5. 環境設定およびデータベース用語 (Environment & Database Terms)
- **プロパティファイル (Property File)**: アプリケーションの動作パラメータや接続情報をキーと値のペアで記述する設定ファイル（例: `application.properties`）。
- **データソース (DataSource)**: データベースへの接続情報を管理し、コネクションプールを提供するオブジェクト。
- **JDBCドライバ (JDBC Driver)**: Java アプリケーションと特定のリレーショナルデータベース間を仲介し、SQL通信を行うためのドライバー。
- **ビューリゾルバー (View Resolver)**: コントローラーから返された論理ビュー名を、実際のJSPなどの物理ファイルパスに解決する仕組み。
- **タイプエイリアス (Type Alias)**: MyBatis において、長いJavaクラスのフルパス名を省略して簡潔に記述できるようにする設定。
- **マッパーXML**: MyBatisにおいて、データベースへ発行するSQLクエリ文をXML形式で記述し、Javaインターフェースと結合するための設定ファイル。
- **プレースホルダー**: SQL文の動的なパラメータ埋め込みにおいて、プリペアドステートメントを生成し、不正なインジェクションを防ぎながら安全に値をバインディングする仕組み。
